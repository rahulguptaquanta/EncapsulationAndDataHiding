# Encapsulation and Data Hiding

A Java project demonstrating encapsulation using a `BankAccount` class with private account number and balance fields, public getters and setters, and validation to prevent negative balances.

## Requirements
- Java JDK 8 or later

## Project Structure
```text
src/
└── com/
    └── internship/
        └── bank/
            ├── BankAccount.java
            └── Main.java
```

## Compile and Run
```bash
javac -d out src/com/internship/bank/*.java
java -cp out com.internship.bank.Main
```
